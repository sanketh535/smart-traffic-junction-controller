# smart-traffic-junction-controller

Four-way smart traffic junction controller using Arduino Uno (ATmega328P) and AVR Assembly.

## Overview
A four-way traffic junction control system featuring timed traffic light sequencing, pedestrian crossing control and automatic Night Mode using an LDR sensor.

## Features
- Four-way traffic light control
- Timed traffic signal sequencing
- Pedestrian crossing with countdown
- Automatic Night Mode

## Hardware
- Arduino Uno (ATmega328P)
- LEDs and resistors
- Push-button
- LDR sensor
- Countdown display

## Programming Language
- AVR Assembly
